# 범어자이 (Beomeo Xi) 홍보 페이지

대구 수성구 범어동 **범어자이**(동대구로80길 40)를 소개하는 정적 홍보 페이지입니다.
빌드 도구 없이 HTML·CSS·JS와 JSON 데이터만으로 동작하며, GitHub Pages에서 그대로 열립니다.

- 라이브: <https://poeticecho.github.io/etc/beomeo-xi/>
- 문의 전화·상담 신청 폼은 의도적으로 넣지 않았습니다.

## 폴더 구조

```
beomeo-xi/
├─ index.html            페이지 본문(모든 섹션의 마크업)
├─ archive.html          공식 홈페이지(xi.co.kr/dgb · m.xi.co.kr) 전수 아카이브 뷰
├─ css/style.css         디자인 토큰과 전체 스타일
├─ js/app.js             내비게이션, 카운트업, 기사 모달, 갤러리/평면도 탭, 라이트박스
├─ js/archive.js         아카이브 렌더러 (목차·탭·라이트박스·영상 파사드)
├─ scripts/build_articles.py  기사별 공유 페이지(articles/{id}/index.html) 생성기
├─ articles/{id}/        기사 하나만 가리키는 공유 URL + OG 미리보기 (자동 생성, 직접 수정 금지)
├─ data/
│  ├─ articles.json      주간 기사 (여기에만 추가하면 목록·발행일이 자동 갱신)
│  ├─ gallery.json       뷰 갤러리 사진과 분류(filters)
│  ├─ floorplans.json    평면 타입·면적·특징
│  └─ archive.json       공식 홈페이지에서 수집한 메뉴·텍스트·표·영상 메타
└─ assets/
   ├─ photos/            최적화된 사진 (파일명은 영문 슬러그)
   ├─ floorplans/        GS건설 공식 평면도 8장
   ├─ archive/           공식 홈페이지 원본 이미지 (dgb 30개 페이지 + 월별 공사사진)
   ├─ og-image.png       SNS 공유 카드 1200×630
   └─ favicon.svg
```

## 공식 홈페이지 아카이브 (`archive.html`)

GS건설 자이 공식 분양 홈페이지(**https://xi.co.kr/dgb**)와 자이 단지정보(**https://m.xi.co.kr/AptComplex/apt_view?aptSeq=467**)의
모든 메뉴를 통째로 보존한 기록입니다. 원문이 닫혀도 남도록 이미지는 전부 내려받아 `assets/archive/` 에 두었고,
외부 핫링크는 없습니다.

- 수집 대상 — 사업안내 5개(사업개요·입지환경·프리미엄·브랜드소개·오시는길), 단지안내 8개, 세대안내 6개(E-모델하우스 포함),
  분양안내 7개(명의변경·84㎡A~E·114㎡ 옵션안내문), 홍보센터 3개(홍보영상·자이TV·언론보도 24건), 공사정보(2022.12~2025.10 월별 공정률 + 현장사진 70장),
  자이 단지정보(평형정보 8타입·특장점)까지 **30개 페이지 · 이미지 109장 · 영상 30편**.
- `data/archive.json` 이 단일 소스입니다. 블록 타입은 `img`(poster=세로로 긴 안내문) / `tabs` / `table` / `text` / `note` / `video` / `links` / `emodel` 입니다.
- 원문이 4,000px인 월별 공사현장 사진은 보기 좋게 2,600px로 줄였고, 모바일용 축소본(동일 도안)은 중복이라 받지 않았습니다.
- E-모델하우스는 3D 파노라마 투어(TDV)로만 동작해 이미지로 담을 수 없어, 투어로 가는 링크와 안내만 남겼습니다.
- 다시 수집하려면 저장소 밖의 크롤러(`beomeo-zai/tools/crawl_archive.py`)를 돌린 뒤 `site/` 를 커밋하면 됩니다.

## 매주 기사 추가하기

`data/articles.json`의 `articles` 배열 **맨 앞**에 객체 하나를 추가하면 됩니다.
페이지의 기사 카드, 발행일, 기사 수가 자동으로 다시 계산됩니다.
**기사에는 사진(`image` · `imageCaption`)이 함께 올라갑니다** — 카드와 기사 전문 모두에 표시됩니다.

```json
{
  "id": "2026-11-30-weekly",
  "date": "2026-11-30",
  "category": "상가 · 생활",
  "title": "기사 제목",
  "excerpt": "목록 카드에 보일 두 줄 요약.",
  "image": "assets/photos/27-live-gate2.jpg",
  "imageCaption": "사진 설명과 촬영일 — 직접 촬영 (2026-11-06)",
  "imageAlt": "화면 낭독기용 사진 설명 (선택)",
  "imagePosition": "50% 45%",
  "body": [
    { "type": "lead",  "text": "리드 문장(굵게 표시)" },
    { "type": "p",     "text": "본문 문단" },
    { "type": "h",     "text": "소제목" },
    { "type": "quote", "text": "가운데 정렬 인용문" }
  ],
  "sources": ["근거 자료 1", "근거 자료 2"],
  "source": "범어자이 홍보자료"
}
```

- **기사에는 사진이 반드시 붙습니다.** `image`(경로)와 `imageCaption`(캡션)은 필수 항목이고, 기사 카드(1면·2면)와 기사 전문(모달) 양쪽에 표시됩니다. 카드 사진을 누르면 기사가 열리고, 전문 사진을 누르면 원본 크기로 크게 볼 수 있습니다.
- `image`가 빠진 기사는 기본 사진(`assets/photos/01-hero.jpg` · GS건설 공식 조감도)이 대신 나오므로 목록이 깨지지 않습니다. 새 기사에도 가능하면 그 기사에 맞는 사진을 꼭 넣어 주세요.
- `imageAlt`는 화면 낭독기용 설명(선택, 없으면 `imageCaption`을 씁니다). `imagePosition`은 세로 사진을 가로 틀에 담을 때 남길 위치를 정하는 값입니다(선택, 기본 `50% 50%`, 예: 인물·간판이 위쪽이면 `50% 30%`).
- `body` 블록 타입은 `lead` / `p` / `h` / `quote` 네 가지입니다.
- `sources`는 기사 끝 "근거 자료" 목록으로 출력됩니다. **확인된 사실과 추정을 섞지 말고, 추정은 문장에서 완화해 쓰세요.**
- JSON 문법(쉼표, 따옴표)만 지키면 됩니다. 오류가 있으면 페이지에 안내 문구가 뜨고 나머지 섹션은 정상 동작합니다.
- **기사를 추가했으면 공유 페이지도 다시 만드세요.** `python3 scripts/build_articles.py`(저장소 루트에서는 `python3 beomeo-xi/scripts/build_articles.py`)를 실행하면 `articles/{id}/index.html`이 기사마다 새로 생성되고, 목록에서 빠진 기사의 옛 페이지는 지워집니다. 생성된 파일도 함께 커밋해야 합니다.

## 기사별 공유 URL (`articles/{id}/`)

기사 하나를 카카오톡·SNS로 보낼 때는 메인 주소 대신 그 기사의 공유 주소를 씁니다.

- GitHub Pages — `https://poeticecho.github.io/etc/beomeo-xi/articles/{id}/`
- Vercel — `https://beomeoxi.vercel.app/articles/{id}/`

이 주소는 그 기사의 `<title>`·`og:title`·`og:description`·`og:image`(기사 사진 절대 URL)·`twitter:*`를 가진 정적 HTML이라, 링크를 붙여 넣으면 **그 기사의 제목·요약·사진이 미리보기로 뜹니다.** 사람이 열면 곧바로 `../../?article={id}`로 넘어가 메인 페이지의 해당 기사 모달이 바로 열립니다(자바스크립트가 없으면 `<meta http-equiv="refresh">` 폴백).

메인 페이지에서는 기사를 열면 주소창이 `?article={id}`로 바뀌고, 닫으면 원래 주소로 돌아옵니다. 기사 모달 하단의 **「공유 링크 복사」** 를 누르면 지금 보고 있는 도메인 기준 공유 주소가 클립보드에 복사되고(`navigator.share`가 있는 모바일에서는 「공유하기」 버튼도 함께 나옵니다) "링크가 복사되었습니다" 안내가 뜹니다. `#article={id}` 해시로 들어와도 같은 기사가 열립니다.

## 사진 추가하기

### 뷰 갤러리 (`data/gallery.json`)

```json
{
  "id": "city-3",
  "src": "assets/photos/12-resident-cityview.jpg",
  "alt": "화면 낭독기용 설명",
  "label": "사진 제목",
  "desc": "한두 줄 설명 (선택)",
  "tag": "city",                         // filters의 key 중 하나
  "credit": "호갱노노 입주민 게시",       // 출처 표기 (필수)
  "creditUrl": "https://hogangnono.com/community/apts/apts-7409999",
  "date": "2026-01-12",
  "source_note": "원문 설명 (선택)"
}
```

- `credit`은 필수입니다. `creditUrl`이 있으면 캡션과 크게 보기 화면에서 "원문 보기" 링크가 되고, 없으면(직접 촬영 등) 출처 표기만 글자로 나옵니다. **출처 없는 사진은 올리지 마세요.**
- 사진 하나가 여러 분류에 들어가야 하면 `"tags": ["live", "night"]`처럼 배열로 적습니다(`tag` 하나만 쓸 수도 있습니다).
- 분류를 새로 만들려면 `filters` 배열에 `{ "key": "…", "label": "…" }`를 추가합니다.
- 사진은 긴 변 1300px 이내, JPEG 품질 82 정도로 줄여 `assets/photos/`에 넣는 것을 권장합니다(원본은 `../../assets/`에 보관).

## 섹션 접기 · 재방문 안내

- `단지개요(#overview)`·`평면도(#plan)`·`입지·FAQ(#location)` 헤더 오른쪽의 **접기/펼치기** 알약 버튼으로 각 섹션을 접습니다. 주간소식(`#news`)과 뷰(`#view`)는 항상 펼침입니다.
- 페이지 맨 아래(푸터 마지막)의 **재방문 시 기본 정보를 닫아드릴까요?** 패널에 `기본 정보 닫기 / 기본 정보 보기` 버튼이 있습니다. 이 버튼은 세 섹션을 한 번에 접거나 펴고, 선택을 `localStorage`의 `beomeo_fold_pref`(`open`·`closed`)에 저장해 다음 방문에도 유지합니다.
- 방문 횟수는 `beomeo_visit_count`로 셉니다. `beomeo_last_visit` 기준 30분 안의 새로고침은 같은 방문으로 보고, **3번째 방문부터는 기본 정보가 자동으로 접힌 채 열립니다**(명시적으로 고른 `beomeo_fold_pref`가 있으면 그 선택이 우선).
- 개별 섹션의 접힘 상태는 `localStorage`의 `beomeo_collapsed_sections`(배열, 예: `["overview","plan"]`)에 저장되어 새 방문·새로고침에도 유지됩니다. 저장값이 깨져 있으면 무시하고 모두 펼친 상태로 시작합니다.
- 접힌 섹션의 내용은 `inert` 처리되어 키보드·스크린리더가 건너뜁니다. 상단 메뉴·앵커로 접힌 섹션(또는 그 안쪽 `#school`·`#faq`)을 찾아가면 자동으로 펼친 뒤 부드럽게 이동합니다.
- `<button class="sec-fold" data-fold="섹션id" aria-controls="섹션id-body">`를 추가하고 본문을 `<div class="sec-body" id="섹션id-body"><div class="sec-body__inner">…</div></div>`로 감싸면 같은 방식으로 동작합니다.

## 하단 푸터 액션

- **맨 위로** — 히어로까지 부드럽게 스크롤합니다(`#to-top`).
- **즐겨찾기 추가** — 북마크 단축키(`Ctrl/Command + D`)와 모바일 '홈 화면에 추가' 방법을 안내하는 모달(`#fav-modal`)을 엽니다. Web Share API가 있으면 '공유하기'가 함께 나오고, '링크 복사'는 클립보드가 막히면 `execCommand`로 대체합니다.

## 범어초 통학 안내

`#location`의 입지 표 아래 `.school` 블록이 도보 실측(정문 1.0km·19분, 쪽문 진입 15~17분대)과 통학버스(등교·하교 각 4회 순환, 차량·시니어 안전도우미, 최대 7년 지원)를 함께 보여 줍니다. 같은 내용이 FAQ 두 항목(배정 학교 / 통학버스와 안전 지원)에도 들어 있습니다. 수치를 바꿀 때 세 곳을 함께 맞춰 주세요.

## 평면도 바꾸기

`data/floorplans.json`의 `types` 배열을 수정합니다. `img` 경로만 바꿔도 탭·표·확대 모달이 함께 갱신됩니다.
새 타입을 넣으면 탭과 "타입 한눈에 보기" 표에도 자동으로 추가됩니다(표에는 아파트 타입만 표시).

JSON을 `fetch`로 읽으므로 파일을 더블클릭하지 말고 간단한 서버로 열어 주세요.

```bash
cd beomeo-xi

```
